# Contributing

Corrections and learning-focused examples are welcome.

When proposing a change:

- state the learning objective;
- show all assumptions and units;
- distinguish system poles from input poles;
- predict the response form before calculating coefficients;
- include a short conceptual interpretation;
- avoid introducing advanced terminology unless the term improves understanding.

For equations, use GitHub Markdown math delimiters: `$...$` inline and `$$...$$` for display equations.
